# job-hunt-agents

[English version](README.md)

Три небольших агента для Claude и Claude Code, которые ведут поиск работы: считают, что стало с откликами, ищут подходящие вакансии и пересобирают резюме без выдуманных фактов.

| Агент | Что делает |
|---|---|
| `stats-collector` | Читает отклики и чаты на сайтах вакансий: какое резюме куда ушло, приглашения, отказы, тишина. Пишет компактный `stats.json` для агентов и понятный `report.html` для тебя. Предполагает, почему не сработало, и находит проблемы в профиле. |
| `vacancy-scout` | Ищет по твоим фильтрам (локации, ключевые слова, удалёнка, зарплата), оценивает каждую вакансию против каждого резюме в процентах и говорит «отправь резюме X» или «пересобери: поменяй Y». |
| `resume-tailor` | Пересобирает резюме под одну вакансию только из подтверждённых тобой фактов. Спрашивает про всё непроверенное, держит ссылку на LinkedIn в каждом резюме, сверяет цифры, собирает md и PDF. |

Принципы: на сайтах вакансий только чтение (никаких автооткликов), минимум токенов (текст страниц вместо скриншотов, скрипты для оценки и отчётов, пропуск уже сохранённого), никаких личных данных в репозитории.

## Поддержка сайтов

| Сайт | Статус |
|---|---|
| hh.ru, rabota.by | Проверено (rabota.by, только чтение). См. `sites/hh.md`. |
| Hirify | Проверено через MCP-коннектор. См. `sites/hirify.md`. |
| praca.by, Jooble, Habr Career, getmatch, superjob.ru, rabota.ru | Не проверено. Агент сам найдёт страницы при первом запуске и запишет их. См. `sites/`. |
| LinkedIn | Экспериментально, по умолчанию выключено. Учитывай правила сайта. |

Pull request с проверенными адаптерами приветствуются.

## Установка

**Claude Code**

```bash
git clone <репозиторий> && cd job-hunt-agents
scripts/install.sh            # копирует агентов в ~/.claude/agents
cp config.example.yaml config.local.yaml   # или пусть агент спросит сам
claude --chrome               # доступ к браузеру для сайтов с логином
```

Либо как плагин: `/plugin marketplace add AlienLynx/job-hunt-agents`, затем `/plugin install job-hunt-agents@job-hunt-agents`.

**Первый запуск: пошаговая настройка**

```bash
python3 scripts/setup.py      # спросит про профиль, сайты, фильтры поиска; запишет config.local.yaml
```

Или скажи «используй job-hunt-setup». Агент проведёт интервью в чате, проверит, что подключены браузер и Hirify, что ты залогинен на каждом сайте, прочитает резюме и соберёт `master-facts.md` из подтверждённых тобой фактов. Дальше: «используй stats-collector», «используй vacancy-scout», «используй resume-tailor для <ссылка на вакансию>».

**Приложение Claude (Cowork / desktop)**

```bash
scripts/pack_skills.sh        # создаёт dist/*.skill
```

Загрузи каждый `.skill` в Настройки, Skills. Для сайтов используется встроенный браузер.

## Каким резюме откликнулись (hh.ru, rabota.by)

Сайт больше этого не показывает. Агент пробует по порядку: (1) необязательный API hh, `scripts/hh_api.py` (нужен токен с dev.hh.ru, на живом API не проверялось, только чтение); (2) вывод по странице «кто смотрел резюме», с пометкой «вероятно»; (3) оставить пустым, заполнить вручную. Для пунктов 2 и 3 токен не нужен.

## Секреты и тесты

Необязательные API-токены кладутся в `.env` (скопируй `.env.example`, он в gitignore) или в `~/.jobhunt/.env`. Читают его только скрипты; агенты его не читают, не печатают и не вводят пароли на сайтах. Лучше токены, чем пароли, а пароли сайтов на диске в открытом виде лучше не хранить.

Тесты: `python3 -m unittest discover -s tests -v` (запускаются и в GitHub Actions при каждом пуше).

## Стоимость

Все агенты работают на самой дешёвой модели (`model: haiku`). Оценка, слияние и отчёты это Python-скрипты, модель только читает страницы и классифицирует. Если качество текста важнее цены, подними модель для `resume-tailor` в `agents/resume-tailor.md` и запусти `python3 scripts/build.py`.

## Другие среды (Codex, DeepSeek Harness и др.)

Не проверялось. Промпты в `agents/*.md` это обычный markdown, скрипты это обычный Python, поэтому всё переносится. См. `AGENTS.md`: прочитай файл агента и `agents/_common.md` и следуй ему. Нужно поправить два места:

- Браузер: в промптах названы инструменты браузера Claude. Подключи browser MCP-сервер (например Playwright MCP) и замени названия. DeepSeek Harness умеет подключать MCP-серверы как источник инструментов, но по умолчанию MCP там выключен.
- Строка `model:` в начале файла относится только к Claude и в других средах игнорируется.

`python3 scripts/setup.py` работает в любом терминале.

## Настройка

Всё хранится в переменных файла `config.local.yaml` (образец `config.example.yaml`): профиль, LinkedIn, пути, включённые сайты, локации, ключевые слова, исключения, формат удалёнки, зарплата, порог совпадения, правила. Меняй файл или скажи Claude «поставь локации Минск и удалёнка», и он отредактирует файл. Если файла нет, агент один раз спросит и создаст его, либо оставит значения только в чате, если ты так скажешь.

Данные (статистика, вакансии, резюме под вакансии) пишутся в `paths.data_dir`. `config.local.yaml` и папка данных в gitignore.

## Вход на сайты

Агенты не вводят пароли. Если ты не залогинен, агент останавливается и просит войти в браузере, после твоего «готово» продолжает. Если браузер не подключён, агент останавливается и объясняет, как подключить.

- Приложение Claude: встроенный браузер.
- Claude Code: Claude in Chrome (https://code.claude.com/docs/en/chrome). Доступно не во всех конфигурациях, поэтому агент проверяет заранее и никогда не подменяет это скрапингом.

## Файлы

```
agents/            исходные промпты (правь здесь), _common.md подставляется в каждый
.claude/agents/    генерируется для Claude Code
skills/            генерируется для приложения Claude
sites/             заметки по сайтам: URL, статусы, известные пробелы
scripts/           setup.py, render_report.py, match.py, check_resume.py, build_pdf.py, build.py
examples/          stats.example.json
```

После правки `agents/*.md` запусти `python3 scripts/build.py`.

## Ограничения

Сайты меняют страницы, адаптеры могут ломаться. Процент совпадения это быстрая оценка по ключевым словам, уточнённая моделью: помощь в ранжировании, а не приговор. Статистика охватывает только отклики, видимые на сайте. Причины отказов это гипотезы. Используй в рамках правил каждого сайта, только чтение, человеческим темпом.
