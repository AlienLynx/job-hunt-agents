# Jooble

Status: **untested**. Aggregator, so the same vacancy often appears on other sites; dedupe by title plus company. Base: `https://by.jooble.org` (Belarus) or `https://jooble.org`. Search uses URL filters; discover the exact query parameters on the first run and record them in `<data_dir>/site-notes.md`.

Same read-only rules as `sites/hh.md`. Never click apply, decline, send or delete. Log in only by the user.
